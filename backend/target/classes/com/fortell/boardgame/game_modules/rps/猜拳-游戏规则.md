# 猜拳游戏规则

**猜拳**支持 **2-8 人**。所有玩家先在房间准备界面入座，座位坐满后由房主开始游戏。

::: note
房主在准备界面可以设置两项参数：**拳法种类**和**猜拳模式**。游戏开始后，本局配置锁定。
:::

## 1. 拳法种类

### 三种

- **石头**（`stone`）
- **剪刀**（`scissors`）
- **布**（`paper`）

克制关系：

- **石头 > 剪刀**
- **剪刀 > 布**
- **布 > 石头**

### 五种

五种拳法在三种拳法基础上增加：

- **蜥蜴**（`lizard`）
- **史波克**（`spock`）

克制关系：

- **石头 > 剪刀、蜥蜴**
- **剪刀 > 布、蜥蜴**
- **布 > 石头、史波克**
- **蜥蜴 > 史波克、布**
- **史波克 > 石头、剪刀**

## 2. 猜拳模式

### 大乱斗

所有在座玩家进入同一个对战区。每一轮中，所有玩家各自选择一种拳法并点击 **确定** 锁定选择。

所有玩家完成选择后，系统公开本轮结果并播报公告：

- `1号玩家：石头，2号玩家：布。胜者为2号玩家！`
- 如果没有唯一胜者，则显示：`本次未分出胜负`

==大乱斗默认进行 9999 轮，此参数不支持修改。==

对战区会显示每名玩家的 **胜场**。每轮只有出现唯一胜者时，胜者的胜场 +1；未分出胜负时无人增加胜场。

### 淘汰赛

系统会随机把玩家分为两人一组。每组玩家同时选择拳法，所有组都分出胜负后才会进入下一轮。

规则如下：

- 胜者进入下一轮。
- 落败玩家进入 __候场模式__，仍然保留座位，但不再参与后续对战。
- 如果某组未分出胜负，该组继续重赛。
- 已经分出胜负的组会等待其他组完成，不会提前进入下一轮。
- 如果本轮玩家人数为奇数，系统会随机安排一名玩家与 **机器人** 对战。

::: warning
机器人会从当前可用拳法中随机出拳。机器人即使获胜，也不会进入下一轮。
:::

## 3. 游戏界面

游戏界面包含四个部分：

- **克制关系**：显示当前拳法种类下的胜负关系。
- **对战区**：显示当前模式下的玩家、选择状态、胜场或分组结果。
- **操作区**：在座且当前需要行动的玩家可以选择拳法并点击 **确定**。
- **公告栏**：显示玩家完成选择、胜负结果、提议结束等信息。

::: note
淘汰赛中，正在对战的玩家只看到自己所在组；观战和候场玩家可以看到全部分组。
:::

## 4. 提议结束

普通玩家可以点击 **提议结束**。提议后，所有玩家会看到：

**玩家XXX提议结束游戏**

如果多名玩家依次提议，会按顺序显示：

**玩家小明、小李提议结束游戏**

提议后的玩家可以再次点击 **取消提议结束**。如果所有提议都被取消，则不再显示提议结束提示。

::: error
只有房主可以真正结束游戏。房主点击 **结束游戏** 后需要确认，确认后房间回到准备界面，所有玩家的入座状态保持不变。
:::
