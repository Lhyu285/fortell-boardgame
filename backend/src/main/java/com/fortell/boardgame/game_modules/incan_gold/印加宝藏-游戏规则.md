# 印加宝藏

## 游戏目标

游戏进行五轮。五轮结束后，宝藏总价值最高的玩家获胜；若相同，则比较神器数量；若仍相同，则比较单个神器最高价值。三项都相同则并列获胜。

绿松石代表宝藏价值：价值 X 的宝藏就是 X 颗绿松石。

## 探险牌堆

初始牌堆包含15张宝藏卡和15张灾难卡。灾难分为塌方、陷阱、妖蛇、傀儡、虫群五种，每种3张。

五张神器的价值分别为5、7、8、10、12，并在第1至第5轮依次加入牌堆。神器只要没有被玩家获得，就会一直保留在探险牌堆中。

## 基础探险流程

每轮开始时加入本轮神器，洗混仍在游戏中的探险牌。所有玩家开始探险，当前轮灾难次数清零。

### 探险阶段

前进一步并翻开一张探险卡：

- 宝藏卡：当前仍在探险的玩家平均分配绿松石，无法均分的部分留在道路上。
- 神器卡：放在道路上，暂不归玩家所有。
- 灾难卡：记录该灾难本轮出现次数。第二次出现同类灾难时，立即进入灾难阶段；否则进入决策阶段。

### 决策阶段

基础规则下，仍在探险的玩家选择“继续探险”或“结束探险”。所有选择完成后，选择结束探险的玩家进入返回阶段，其他玩家继续下一次探险阶段。

### 返回阶段

返回玩家带回本次探险中已获得的宝藏，然后平均分配道路上所有留存的绿松石。无法均分的部分继续留在道路上。

如果本次恰好只有一名玩家返回，该玩家获得道路上的全部神器；多人返回时神器继续留在道路上。

### 灾难阶段

仍在探险的玩家本轮收益全部清零；已经返回营地的玩家不受影响。道路上的本轮收益也不计入任何玩家。随后永久移除一张对应灾难卡，并洗混剩余探险牌，本轮结束。

普通结束时，道路上的未分配绿松石不计入任何玩家；未被获得的神器和其他仍在游戏中的探险牌重新洗混，为下一轮准备。

## 盗贼扩

房主可以在创建房间或等待房间中选择是否启用盗贼扩。启用后，决策阶段增加“盗窃”选项，每名玩家每轮最多使用一次。

所有玩家提交决策后，先公开盗贼玩家。每名盗贼从当前仍未返回且本次没有选择盗窃的玩家中选择一名目标，所有盗贼目标提交完成后同时公开。

- 目标选择继续探险：盗窃无事发生。
- 目标选择结束探险：目标交出本次探险获得的最多3颗绿松石，不足则全部交出。
- 多名盗贼选择同一目标时，这些绿松石由盗贼均分，无法均分的部分返还目标。
- 盗贼完成盗窃后继续探险，即使没有偷到绿松石。
- 如果没有可盗目标，盗窃动作视为已使用，盗贼仍继续探险。

盗窃结算完成后，再按正常规则处理返回阶段。

## 事件扩

房主可以在创建房间或等待房间中选择是否启用事件扩。启用后，每轮开始时从五张不同的事件牌中随机抽取一张；事件牌不会重复，且只在本轮生效。事件牌会公开显示给所有玩家。

- **卓柏卡布拉**：如果一次决策中恰好只有一名玩家选择返回，或某名玩家成为神庙中最后一名仍在探险的玩家，该玩家会被怪物攻击。被攻击的玩家算作返回营地，失去本轮获得的全部绿松石，且不能获得神器或道路上的绿松石。
- **双重挑战**：每次探险连续翻开两张探险卡并依次结算，翻完后再统一进入决策阶段。如果第一张已经触发灾难阶段，则不再翻第二张；第二张触发灾难时照常结算。
- **无尽财富**：每种灾难第一次出现时，在该道路上增加5颗绿松石，按道路绿松石的正常返回分配规则处理。
- **三重挑战**：同一种灾难第三次出现时才触发灾难阶段；第二次出现不结束探险。第三次触发后永久移除一张对应灾难牌。
- **后会有期**：翻出宝藏卡时，该卡的全部绿松石留在道路上，玩家只能在返回阶段分配道路上的绿松石。
