# 环中物语

房主选择主持人后，主持人获得三条隐藏规则：情境、词汇、属性。竞猜者通过主持人放置的词语和其他玩家的尝试，推理词语应该放入哪个区域。

## 流程

1. 房主设置难度和观战视角，开始游戏。
2. 房主选择一名玩家作为主持人，也可以随机选择。
3. 主持人根据隐藏规则先放置 3 张词语卡。
4. 竞猜者从主持人下一座位开始轮流行动。
5. 竞猜者放置正确后可以结束回合，也可以继续放置。
6. 竞猜者放置错误后，补 1 张词语卡并强制结束回合。
7. 主持人回合开始前，如果有竞猜者手牌清空，该玩家获胜。

## 区域

- 情境：红色区域
- 词汇：黄色区域
- 属性：蓝色区域
- 情境+词汇：红黄区域
- 情境+属性：红蓝区域
- 词汇+属性：黄蓝区域
- 情境+词汇+属性：红黄蓝区域
- 无关：无关区域

## 区域含义

- 情境：通常情况下，物品的使用方式或可能的出现地点。例如“适合拿来送礼”、“与体育运动有关”
- 词汇：物品名称的拼写或组成。例如“首尾字母相同”、“有3个音节”
- 属性：物品的物理属性。例如“含有金属”、“可以移动”

## 观战视角

- 上帝视角：可以看到主持人的三条隐藏规则和所有玩家手牌。
- 玩家视角：可以看到所有玩家手牌，但不能看到主持人的隐藏规则。
